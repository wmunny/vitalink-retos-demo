# Vitalink Retos · maqueta del panel de empresa

Maqueta navegable (HTML estático, sin servidor) de cómo vería RRHH los retos de Vitalink Retos:
inicio con indicadores, retos y asistente de creación con vista previa en la app,
clasificaciones, comunicación (mensajes, muro y kit de lanzamiento), premios, verificación de
actividad, informes y ajustes de privacidad.

Todos los datos son ficticios y nada se guarda. Abre `index.html` o la página publicada.
Enlaces directos: `#retos`, `#nuevo-reto`, `#clasificaciones`, `#comunicacion`, `#premios`,
`#verificacion`, `#informes`, `#ajustes`.
